# macrocraft

An RTS where unit micro can be programmed ahead of the battle.

Most micro is just carrying out known attack patterns, like retreating while the weapon reloads, turning to fire, then retreating again. macrocraft packages those patterns so units can use their full ability without hand execution, and lets players customize or write their own patterns before battle. If you want to prepare, nothing requires execution. You still have to react to your opponent.

See [docs/design.md](docs/design.md) for the design and [docs/glossary.md](docs/glossary.md) for terms.

## Running

Built with [Godot 4](https://godotengine.org/). Open `project.godot` in the Godot editor (4.5 or newer) and press F5.
